来源：[agent-taste-seed-system](https://github.com/hhx465453939/agent-taste-seed-system)，作者 hhx465453939。2026-10-16 核对提交 f447763a8e106effb2a4c8fdc5fd93cbb2ca2045。重点阅读上游 [TASTE.md](https://github.com/hhx465453939/agent-taste-seed-system/blob/f447763a8e106effb2a4c8fdc5fd93cbb2ca2045/TASTE.md) 与 [AGENT-INJECTION.md](https://github.com/hhx465453939/agent-taste-seed-system/blob/f447763a8e106effb2a4c8fdc5fd93cbb2ca2045/AGENT-INJECTION.md)。本页是针对工作台的适配说明，未复制上游代码、种子库或艺术素材。

## 在共创流程中的位置

需求与任务优先级 → 风格决策 → frontend 专用技能制作 UI → 实际预览 → 开发者确认 → 实现与回归。Taste Seed 提供风格选择依据，frontend-design 或 design-taste-frontend 等实际可用技能负责界面设计执行；能力重叠时指定一个主设计者，避免叠加冲突规则。

先通过互动确定用户期待的体验，如安心、清晰或专注。随后按需查看情绪索引与相关代码风格卡，选择一个主要方向；确有需要再加一个辅助方向。将色彩、光影、线条、构图和情绪逐项映射到可执行的 UI 参数。完成后检查实际效果并记录开发者反馈，确认后的参数进入项目 token 与 UI-DESIGN。

## Workbench 参数转译示例（本社区建议）

例如患者记录工作台可讨论“清晰”为主、“温和”为辅；这是待用户确认的候选，不是默认业务方案。

| 风格维度 | 工作台要做的具体决定 | 示例 |
| --- | --- | --- |
| 色彩 | 语义 token、强调与状态色 | 薄荷绿组织内容，橙色突出主要动作；状态另用文字/符号说明 |
| 光影 | 面板分层、阴影与透明度 | 轻阴影分层；正文区域保持足够实底与对比 |
| 线条 | 图标、描边、图表线宽 | 统一图标线宽，折线保持几何比例 |
| 构图 | 栅格、对齐、密度与留白 | 按任务分组，组间距大于组内距 |
| 情绪 | 文案、动效与操作反馈 | 表达支持和可操作下一步；装饰动效可停用 |

阅读、键盘操作、信息完整、宿主边界、原型合同优先于装饰。上游面向广泛视觉创作的配色/造型规则须按工作台语义调整，不机械限制必要的图表系列和状态，也不为艺术效果删除功能或降低可读性。具体参数必须在真实业务容器、大字与减少动效设置下验收。

## 按需使用和便携性

开发环境已部署 taste 时，先读取其实际技能入口，按技能根目录解析 references，只查当前任务有关的索引和卡片，不一次加载整库。未部署时可只读访问上游，或采用本社区指南的替代流程；记录实际阅读的文件、提交与不可用项，不声称技能已经激活。

上游当前要求种子库置于技能内部或无技能机制时的稳定独立目录，避免被 workspace 清理。上游 README 的部分部署示例与较新 TASTE/注入文档存在路径差异，若要安装，应以锁定提交中的目标 Agent 部署文档与实际脚本核对。脚手架不自动改写全局 Agent 规则，不把个人绝对路径变成生成项目的运行依赖。

仓库树核对时未发现独立 LICENSE/COPYING 文件；如需随脚手架分发原文、全库或素材，先明确对应许可。本次仅加入方法适配、引用和项目记录结构，无需安装新依赖。

## 反馈沉淀

将目标感受、主辅方向、转译参数、预览证据和用户接受/拒绝原因填入 templates/UI-DESIGN.md。项目反馈保存在项目内；修改上游个人种子库副本属于独立动作。下次设计先查看已确认偏好，避免每次从默认样式重新试错。

## 已验证风格类型 · 治愈暖纸 Healing Paper（2026-11-21 · 用户确认保留）

> 来源仓：squamous-cell-skin-cancer-workbench（CSCC · v0.2.0-rc.5，commit 5068143/d5f96eb）。
> 用户在真机浏览器两轮反馈（「设计太丑」→「按钮太丑」）后确认保留本风格；token 预设与按钮配方已沉淀为 starter 资产（见下）。

**主基因：吉卜力手绘亲和（治愈）**——被托住的安心；**辅基因：瑞士平面（信息骨架）**——左对齐、清晰层级、唯一强调色、tabular 数字。只混一层。适用：患者/照护者信息工具（表格、化验、随访记录）；纯治愈基因会被信息密度冲散，辅基因必须压住骨架。

### 五基因 → 参数

| 基因位 | 参数 |
| --- | --- |
| 色彩 | 米白纸底 `#faf7f0` + 草木绿 `#4a7c59`（唯一 CTA，面积 ≤10%）+ 暖墨 `#4a4238`/暖灰 `#8a8072`/暖分隔线 `#e7dfcf`；语义状态暖色调（danger=赭 `#b3572f` 非正红）；图表暖四色（草木绿/天空蓝/赭/暖金）；**阴影一律暖色 `#e8e0d0` 系，禁纯黑纯灰** |
| 光影 | 柔和日光感：卡片无阴影（1px 暖分隔线），阴影只给浮层（panel/drawer/toast）；主按钮暖色微影 |
| 笔触 | 衬线标题（Noto Serif SC）做手作人文感 + 正文柔黑一家到底；图标/花形点缀每页 1–3 处 |
| 构图 | 左对齐统治；卡片大圆角 16px、动作胶囊 999px、表单控件 12px；断点 1180/900/600 |
| 情绪 | 「每天要按几下记录」的可靠治愈——不是营销页的甜 |

### 按钮配方（三轮反馈收敛）

- 动作**全胶囊** + 三级层级：主=实心草木绿（每屏唯一）/ 次=暖纸贴纸（solid soft 无框）/ 幽灵=透明+暖 hover；active 下沉 1px。
- **必查坑**：模板生成的顶栏按钮极易无 class 吃 UA 默认样式（灰盒方角系统字体）——上线前扫无 class 原生 button。
- 默认=**keycap 键帽下沉**（2026-11-21 用户采纳 C）；**色调默认暖纸**，可选淡绿/淡粉/淡紫（`html[data-tone]` 令牌块）。互动形态：看板 hero 挂页内「风格预览选择器」（style-picker.js + buttons-pill-system.css），按钮效果 A–F × 色调四档点选即时切换。
- **开发版不得含选择器**（2026-11-21 用户规则）：选择器只在 M2 demo 确认阶段存在。定稿后构建期剔除——原型 `var SHOW_STYLE_PICKER = true` → `migrate-public` 置 `false` + `expected()` 断言产物含量 false 不含 true；测试双向断言（原型 true / 开发版 false）。**禁止运行时 remove 隐藏**（脆弱、闪烁、不可断言）。
