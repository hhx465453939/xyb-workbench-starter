# 08 · TASTE-SEED 风格种子与视觉设计规范

本文档为小 X 宝家族工作台的前端视觉基线与官方母题规范。

## 核心设计哲学：医学专业度与患者心理抚慰的平衡

患者工作台不是冰冷的医院 EMR 后台，也不是浮躁的商业营销 App。在视觉设计上，必须平衡：
1. **主基因（情绪层面）**：抚慰与安全感——缓解患者与照护者的病痛焦虑，提供被托住的踏实感；
2. **辅基因（信息层面）**：瑞士平面现代排版——左对齐统治、严格层级、唯一主要 CTA、Tabular 数字防跳动；
3. **医疗无障碍（A11y / WCAG 2.2）**：文本与背景对比度严格符合 WCAG 2.2 AA 级（普通文本 ≥4.5:1）或 AAA 级（≥7.0:1），触控目标满足无障碍标准，并在大字模式和减少动效下保持完全可用。

## 官方三大母题规范（2026-11-22 升级）

针对家族 86 个罕见病与 25+ 癌种的不同临床场景，脚手架提供三大官方母题体系：

### 1. 治愈暖纸（Healing Paper）
- **适用病种**：长程肿瘤慢病、慢性免疫性疾病、康复期随访（如乳腺癌、鳞癌、皮肌炎、狼疮）。
- **基因与调性**：主基因吉卜力手绘亲和 + 辅基因瑞士平面骨架。
- **五基因参数**：
  - **色彩**：米白纸底 `#faf7f0` + 暖墨字 `#4a4238` + 草木绿 `#4a7c59`（唯一 CTA）+ 优化次级文本 `#6e6456`（对比度 **4.7:1**，达到 WCAG AA 级）；阴影一律暖色 `#e8e0d0`，禁纯黑纯灰。
  - **光影**：柔和日光感，卡片无厚重阴影（1px 暖细线），浮层给轻微暖影。
  - **笔触**：标题适度手作衬线（Noto Serif SC）+ 正文柔黑；低分屏带抗断笔现代无衬线回退。
  - **构图**：卡片大圆角 16px、动作胶囊 999px、表单控件 12px。
  - **情绪**：可靠、温润、每天按几下记录的日常陪伴。
- **资产文件**：`assets/tokens.healing-paper.json` / `assets/tokens.healing-paper.css`。

### 2. 澄净冷青（Clinical Sage）
- **适用病种**：出血性疾病、心血管急症、血液肿瘤（如血管性血友病 3 型、获得性血友病、心包炎、MDS、ITP、TTP）。
- **基因与调性**：主基因现代医学理性 + 辅基因北欧克制结构。
- **五基因参数**：
  - **色彩**：清冷纸底 `#f4f7f6` + 冷炭字 `#202d2c`（对比度 **12.2:1**）+ 冷青松石 `#1f5f5b`（唯一 CTA）+ 次级文本 `#526664`（对比度 **5.36:1**，达 WCAG AA 级）；警示采用深赭红 `#ba4328`，避免刺眼大红引发过度惊恐。
  - **光影**：平整清晰，极简微投影，强化数据对比。
  - **笔触**：纯现代无衬线黑体（PingFang SC / Hiragino / Segoe UI），彻底杜绝 Windows / Android 低分屏断笔问题。
  - **构图**：严整 12px 卡片圆角、全胶囊 999px 按钮。
  - **情绪**：冷静、客观、精确、给急重症家属以专业稳定的信赖感。
- **资产文件**：`assets/tokens.clinical-sage.json` / `assets/tokens.clinical-sage.css`。

### 3. 晨曦大字（Dawn Clarity）
- **适用病种**：老年退行性病变、伴随眼疾或视力障碍群体（如帕金森、阿尔茨海默、老年性白内障/青光眼伴发慢病）。
- **基因与调性**：主基因极端无障碍包容性（WCAG 2.2 AAA 级）+ 辅基因明晰大字骨架。
- **五基因参数**：
  - **色彩**：明快白底 `#f8f9fa` + 墨黑字 `#111827`（对比度 **15.4:1**）+ 明晰蓝 `#0052cc`（对比度 **7.04:1**）+ 次级文本 `#4b5563`（对比度 **7.2:1**，全线超 WCAG AAA 级 7.0:1 严苛标准）。
  - **光影**：高反差边缘线，强化卡片区域边界（`#cbd5e1`）。
  - **笔触**：加粗纯黑体，大字号基线 **17px**（小字不低于 14px），高可见 3px 聚焦框。
  - **构图**：紧凑 10px 圆角，按钮与触控区域最小高度 **≥48px**（满足无障碍触控目标尺寸）。
  - **情绪**：极度易读、零认知障碍、大字清晰。
- **资产文件**：`assets/tokens.dawn-clarity.json` / `assets/tokens.dawn-clarity.css`。

## 病房低照度「暗纸护眼模式（Paper Twilight）」

患者与家属常在深夜病房、关灯床头记录用药、输注或出血发作。脚手架在三大母题中内置了**非发光纯黑**的深墨暗纸方案：
- **底色原则**：拒绝 OLED 纯黑（`#000000` 在查阅图表和化验单时黑白对比过于强烈，易引起眩光和光晕）；采用深墨暖灰纸底（`#18191a` / `#171a1a` / `#121314`）。
- **文本对比度**：正文使用柔和暖米白（`#e3ded6`，对比度 ~11.5:1），次级文本严格保持在 4.5:1 以上，关灯环境下柔和清晰不刺眼。
- **切换方式**：支持通过 `html[data-twilight="true"]`、`html[data-theme="dark"]` 或 `@media (prefers-color-scheme: dark)` 激活。

## 医疗图表 Viz 语义色彩体系

三大母题在 DTCG JSON 与 CSS 中统一定义了医疗图表专用语义令牌，防止图表曲线与状态警示色混淆：
- `--wb-viz-band-normal`：化验参考值正常区间带（低饱和半透明阴影带）。
- `--wb-viz-marker-abnormal`：化验异常/偏高偏低警示标记点（高警示度赭红）。
- `--wb-viz-event-infusion`：因子输注/化疗/用药事件纵向对齐线。
- `--wb-viz-event-bleed`：出血/疼痛/发作事件区间带。

## 按钮配方与原型挑款

- 动作**全胶囊 999px** + 三级层级：主 = 实心强调色（每屏唯一 CTA） / 次 = 贴纸色（solid soft 无框） / 幽灵 = 透明 + hover；active 下沉。
- 默认按钮效果：**C 键帽（keycap）**（白纸面 + 暖线描边 + 底部 2px 实影，按下下沉 2px 实影收起）。
- 原型互动选择器：`assets/patterns/style-picker.js`，可在原型首页英雄卡一键切换三大母题、6 种按钮变体、夜间暗纸与细节色调。
- 定稿固化：使用 `node scripts/apply-theme.mjs <项目目录> --theme clinical-sage --variant keycap` 快速固化，构建期 `migrate-public` 自动剔除选择器并由单元测试双向断言。
